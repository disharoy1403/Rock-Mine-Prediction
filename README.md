# 🪨 Rock vs Mine Prediction using Logistic Regression

## 📌 Project Overview
This project implements a **Machine Learning classification model** to predict whether an object detected by **SONAR signals** is a **Rock** or a **Mine**.  
The model is built using **Logistic Regression**, a widely used supervised learning algorithm for binary classification problems.

The project demonstrates a complete **machine learning pipeline**, including data preprocessing, model training, evaluation, and prediction on new input data.

---

## 📂 Dataset Information
- **Dataset Name**: SONAR Dataset
- **Total Samples**: 208
- **Number of Features**: 60 (numerical)
- **Target Labels**:
  - `R` → Rock  
  - `M` → Mine  

---

## ⚙️ Technologies & Libraries Used
- Python  
- NumPy  
- Pandas  
- Scikit-learn  
- Google Colab / Jupyter Notebook  

---

## 🧠 Machine Learning Model
### Logistic Regression
- Used for **binary classification**
- Efficient and interpretable model
- Suitable for high-dimensional numerical data

---

## 🔄 Steps Performed
1. Data loading and inspection
2. Data preprocessing
3. Splitting data into training and testing sets
4. Training the Logistic Regression model
5. Evaluating model performance using accuracy score
6. Making predictions on new SONAR input data

---

## 📊 Model Performance

| Dataset | Accuracy |
|-------|----------|
| Training Data | ~83% |
| Testing Data | ~76% |

---

## 🧪 Output
The trained model predicts whether the given SONAR signal corresponds to:
- **Rock**
- **Mine**
